FIELD NOTES

A record of the standings.

An independent archive of public Metal Waltz PvP rankings, collected with dedicated accounts. Grandeur and ranking order come from the game servers.

What does “complete” mean?

Each collection follows the ranking pages until the server returns an empty page. This includes every server-exposed ranking entry; it does not establish the total registered population. Positions may change while a collection is running.

Why are some names unavailable?

A ranking position and its Grandeur can be available even when a name lookup fails. Those rows remain visible as “Name unavailable.” In the initial Columbus iOS collection, both tested name queries returned server code 48 for 1,453 rows. The cause of that response is unknown.

Which vehicles are shown?

The portraits show each commander’s returned public vehicle list. Select a portrait to see the vehicle and maiden name. Empty slots mean the server returned fewer than six vehicles; an unavailable list is marked separately. Portraits use the corresponding game artwork, including rendered portraits for Live2D vehicles.

When is the archive updated?

The collection schedule and run history are published in the GitHub Actions log (opens in a new tab). Each server shows the time of its last successful snapshot. If a refresh fails, the last available snapshot is retained and marked.
